# Cálculo de consumo de aparelho
# Autor: Anna Jullya

Este projeto em Python foi criado para praticar o ciclo de **Entrada > Processamento > Saída**
O programa solicita o **Nome do aparelho**, a **Potência** e o **Tempo estimado em horas de uso**, calcula o **Consumo mensal** do Aparelho ao multiplicar a potência pelas horas e por 30, dividindo o resultado por 1000. Calcula o **Custo** ao multiplicar o resultado do consumo por 0,75(0.75 no código).

Para a execução é necessário escrever o que foi solicitado.
